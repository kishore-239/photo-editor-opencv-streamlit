# Photo Editor using OpenCV & Streamlit

## Overview

This project is a web-based Photo Editor built using OpenCV and Streamlit.
It allows users to upload an image, apply various transformations and filters, and download the edited result.

The application demonstrates fundamental image processing techniques along with an interactive user interface.

---

## Features

* Upload image
* Resize image using sliders
* Adjust brightness and contrast
* Apply filters:

  * Grayscale
  * Blur
  * Sharpen
  * Warm tone
  * Edge Detection
* Rotate image
* Portrait-style background blur (face-based)
* Download edited image

---

## Tech Stack

* Python
* OpenCV
* Streamlit
* NumPy
* Pillow

---

## How to Run Locally

1. Clone the repository:

```
git clone https://github.com/kishore-239/photo-editor-opencv-streamlit.git
cd photo-editor-opencv-streamlit
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Run the app:

```
streamlit run app.py
```
